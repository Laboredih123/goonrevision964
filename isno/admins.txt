# To add an administrator, place their ckey (their BYOND key, stripped of
# whitespace and capital letters) followed by a space, a dash, a space, and
# all the positions you want to give them. All positions are independent -
# it's possible to be a GM and not a moderator, a moderator and not a GM,
# or both, for instance.
#
# The valid positions are:
# GM - short for Game Master. Can spawn items, start rounds, and generally
# do things related to SS13 itself, rather than the players.
# Mod - Can ban, mute, jobban, and so on. Does things related to the players rather
# than SS13 itself. Can ban for a maximum of 1 day or 25 rounds.
# Admin - Like a mod, but can ban for up to a week or 200 rounds.
# Superadmin - Like an admin, but can ban for an arbitrary number of weeks or rounds.
# Developer - Has access to debugging powers, such as deleting and spawning objects.
# Host - Has all powers of all other ranks.

# Don't put any whitespace after the rank - "Host " is not a 
# rank, and is equivalent to no rank at all.
